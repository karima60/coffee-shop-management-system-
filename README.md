# Coffee Shop Management System

A desktop management application for a coffee shop, built with **C# (.NET) Windows Forms** and **SQL Server**, using object-oriented programming principles.

## Features
- Category, Product, and Sales management via Windows Forms UI
- SQL Server database connectivity (`DBConnect.cs`)
- Login-based access and a main dashboard

## Tech Stack
- C# / .NET (Windows Forms)
- SQL Server
- Visual Studio

## Build & Run
1. Open `CoffeeShopProject.sln` in Visual Studio.
2. Restore the SQL Server database / update the connection string in `DBConnect.cs`.
3. Build and run (F5).
